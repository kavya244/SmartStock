
# SmartStock – Product Inventory Management

SmartStock is a full-stack product inventory management application built using React, Spring Boot, and MySQL.

## Features

- Login interface
- View all products
- Add new products
- Edit existing products
- Delete products
- Search products
- Store product data in MySQL

## Technologies Used

**Frontend**
- React
- JavaScript
- CSS

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- REST API

**Database**
- MySQL

## Project Structure

```text
SmartStock/
├── SmartStock-Frontend/
└── SmartStock-Backend/
```

## Purpose

This project was developed to practice full-stack application development, including frontend design, REST API integration, backend development, and database operations.
